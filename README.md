# Expense Tracker (Java + SQLite + Swing)

A minimal Expense Tracker desktop application built using **Java Core**, **JDBC (SQLite)**, and **Java Swing**.

## 📁 Project Structure
## 💡 Features
- Add and view expense entries
- SQLite-based data persistence
- Clean, minimal Swing GUI

## 🚀 How to Run
1. Download [SQLite JDBC Driver](https://github.com/xerial/sqlite-jdbc/releases) and place the JAR inside the `lib/` folder.
2. Compile:
   ```bash
   javac -cp ".:lib/sqlite-jdbc-<version>.jar" Main.java
   Run:
